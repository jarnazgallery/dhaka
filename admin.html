Google Apps Script সেটআপ

  1. কম্পিউটারে cloud-orders.gs খুলে সব কোড কপি করুন
  2. script.google.com → New project → পেস্ট → Save
  3. Run → setup → Allow (একবার অনুমতি দিন)
  4. Deploy → New deployment → Type: Web app
  5. Execute as: Me · Who has access: Anyone → Deploy
    ⚠️ "Anyone with a Google account" দিলে Sync ভাঙবে
  6. ওয়েব অ্যাপ URL (/exec) নিচে পেস্ট → Test Sync → গ্রিন হলে Save
  7. ডাউনলোড হওয়া site-config.js হোস্টিংয়ে আপলোড করুন
